simcoon

Constitutive laws, material-point simulation and mean-field micromechanics for nonlinear and heterogeneous materials.

simcoon is a C++ library with a Python interface. It provides constitutive laws (elastoplasticity, viscoelasticity, hyperelasticity, shape memory alloys, damage), a thermomechanical material-point solver under mixed strain and stress control, finite-strain kinematics with several objective rates, and mean-field homogenization of composites. Its laws serve as user materials in fedoo, Abaqus and Ansys, on microstructures generated with microgen.

Tensor2 and Tensor4 Examples

Hello, elastoplasticity

import numpy as np
from simcoon import solver

props = np.array([70000.0, 0.3, 1.0e-5, 300.0, 1000.0, 0.3])  # E, nu, alpha, sigma_Y, k, m
load = solver.StepMeca(control="stress", value=[450.0, 0, 0, 0, 0, 0], ninc=100)
unload = solver.StepMeca(control="stress", value=[0.0, 0, 0, 0, 0, 0], ninc=100)

res = solver.solve(solver.Block(steps=[load, unload], ncycle=3), "EPICP", props, nstatev=8)
print(res["Strain"][0, -1], res["Stress"][0, -1])

simcoon.solver.solve() runs the loading blocks in memory and returns the whole history as numpy arrays. See In-memory Python solver for the loading objects and Constitutive model (UMAT) catalog for the list of laws and their parameters.
